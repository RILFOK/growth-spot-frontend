# Frontend

React + Vite frontend для проекта growth-spot.ru.

## Стек
- React
- Vite
- react-router-dom
- react-hook-form
- axios

## Запуск локально
```bash
npm install
npm run dev
```

## Сборка
```bash
npm run build
```

## Настройки окружения
При необходимости можно использовать `.env`:

```env
VITE_API_URL=/api
```

## Production
Production-сборка выкладывается в:
`/var/www/project1/frontend`

## Основные разделы
- публичный сайт
- форма заявок
- админка
- IP-фильтр
- управление заявками и пользователями
