# Frontend — роутинг

## Общая схема
Во frontend используется клиентский роутинг на базе `react-router-dom`.

Маршруты разделены на две основные группы:
- публичные;
- административные.

## Публичные маршруты
Во frontend реализованы следующие публичные маршруты:
- `/` — главная страница;
- `/privacy` — политика конфиденциальности;
- `/privacy-full` — расширенная политика;
- `/consent` — согласие на обработку персональных данных;
- `/terms` — условия использования.

Эти страницы доступны без авторизации.

## Административные маршруты
Для административной части используются следующие маршруты:
- `/admin/login` — вход в админку;
- `/admin` — dashboard.

Доступ к административному интерфейсу завязан на состояние авторизации пользователя.

## Особенности
Frontend-роутинг имеет несколько важных особенностей:
- Яндекс.Метрика не подключается на `/admin/*`;
- административный доступ строится вокруг JWT-токена в `localStorage`;
- публичные и административные страницы разделены логически и функционально;
- часть поведения интерфейса зависит от текущего маршрута, например подключение аналитики.
