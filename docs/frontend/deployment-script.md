# Исторический скрипт развёртывания

В ранней версии проекта был скрипт, который одной командой синхронизировал frontend и backend в каталоги `project1`, выполнял `rsync --delete`, перезапускал PM2 и перезагружал nginx. Он относился к прежней инфраструктуре и **не предназначен для запуска** из этой публичной портфельной копии.

Для проверки текущей версии используйте только локальные команды:

```bash
npm ci
npm test
npm audit
npm run build
npm run preview -- --host 127.0.0.1
```

Актуальная структура сборки и требования к безопасному стейджингу приведены в [инструкции по сборке](deployment.md). Действующий `growth-spot.ru` обслуживается независимым Next.js-проектом `RILFOK/growth-spot-nev`; архивный React frontend не следует публиковать поверх него.
