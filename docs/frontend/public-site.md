# Frontend — публичный сайт

## Назначение
Публичная часть frontend отвечает за отображение основного сайта для посетителей, презентацию услуг и сбор заявок через форму обратной связи.

Она включает главную страницу, общие layout-компоненты и юридические страницы.

## Главная страница
Главная страница собирается из набора последовательных секций:

- Hero
- Services
- Benefits
- ForWhom
- Process
- Pricing
- WhatYouGet
- FAQ
- Contact

Такой подход позволяет строить лендинг как композицию независимых блоков, каждый из которых отвечает за отдельную часть контента.

## Header
Компонент `Header` реализует:
- навигацию по якорям;
- переключение темы;
- мобильное меню;
- CTA-кнопку перехода к форме заявки.

Он используется как основная верхняя панель публичного сайта и адаптирован для desktop и mobile сценариев.

## Footer
Компонент `Footer` содержит:
- навигацию;
- список услуг;
- контакты;
- ссылки на соцсети;
- юридические документы.

Часть значений подгружается из `SettingsContext`, что позволяет изменять данные футера через backend-настройки без правки frontend-кода.

## Связанные элементы
Публичная часть также использует:
- глобальные настройки сайта;
- SEO-компоненты;
- аналитику;
- форму отправки заявки.
