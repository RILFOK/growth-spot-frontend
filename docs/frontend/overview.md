# Frontend — обзор

Frontend проекта `growth-spot.ru` представляет собой SPA-приложение на React.

Он отвечает как за публичную часть сайта, так и за административный интерфейс, через который выполняется управление контентом, заявками и пользователями.

## Основные функции
Frontend включает следующие основные возможности:
- публичный сайт-лендинг;
- юридические страницы;
- форму отправки заявок;
- административную панель;
- управление заявками;
- управление пользователями;
- управление настройками сайта;
- настройку 2FA;
- управление IP whitelist и blocked IP;
- интеграцию с Яндекс.Метрикой.

## Технологический стек
Во frontend используются:
- React 19
- Vite 7
- Tailwind CSS 4
- React Router DOM 7
- Axios
- React Hook Form
- OTPAuth
- `react-qr-code`

## Роль в проекте
Frontend отвечает за:
- отображение публичного интерфейса сайта;
- взаимодействие пользователя с формами;
- работу административной панели;
- интеграцию с backend API;
- отображение и редактирование данных, полученных с сервера;
- подключение аналитики и управление SEO-метаданными.
