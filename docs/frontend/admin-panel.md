# Frontend — админ-панель

## Назначение
Административная панель предназначена для управления внутренними данными проекта и доступна по маршруту `/admin`.

Через неё выполняются:
- просмотр и обработка заявок;
- управление пользователями;
- изменение настроек сайта;
- настройка двухфакторной аутентификации;
- управление IP-безопасностью;
- смена пароля текущего пользователя.

## Основные возможности
Админ-панель поддерживает следующие функции:
- просмотр заявок;
- смена статуса заявок;
- удаление заявок;
- управление пользователями;
- изменение ролей;
- смена пароля;
- настройка 2FA;
- управление настройками сайта;
- управление whitelist и blocked IP.

## Dashboard
Главная административная страница — `/admin`.

Именно через dashboard пользователь получает доступ ко всем административным разделам системы.

## Особенности работы
Dashboard имеет несколько важных особенностей:
- polling заявок каждые 30 секунд;
- сохранение активной вкладки в `localStorage`;
- проверку сессии через `/auth/me`;
- отображение плавающих статусов интерфейса.

### Плавающие статусы
В интерфейсе отображаются:
- состояние API заявок;
- состояние API настроек;
- статус 2FA.

Это позволяет быстро понять, доступен ли backend и включена ли дополнительная защита аккаунта.

## Компоненты админки
Основные административные функции реализованы через отдельные компоненты:
- `LeadsTable`
- `UsersManager`
- `TwoFactorSetup`
- `ChangePassword`
- `IPWhitelistManager`
- `Settings`
