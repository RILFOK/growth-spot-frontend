# Frontend — установка и запуск

## Требования
Для локальной разработки frontend необходимы:
- Node.js
- npm

## Установка зависимостей
Для установки зависимостей выполните:

`npm install`

## Локальный запуск
Для запуска frontend в режиме разработки используйте:

`npm run dev`

После этого приложение будет доступно через dev-сервер Vite.

## Production build
Для сборки production-версии используйте:

`npm run build`

В результате будет создана директория `dist/` с готовыми файлами для публикации.

## Preview
Для локального просмотра production-сборки можно использовать:

`npm run preview`

## Переменные окружения
Frontend поддерживает переменные окружения.

Пример:

`VITE_API_URL=/api`

### Назначение
- `VITE_API_URL` — базовый URL для обращения к backend API.

Если переменная не задана, frontend использует значение по умолчанию `/api`.

## Production директория
Production-версия frontend размещается в директории:

`/var/www/project1/frontend`
