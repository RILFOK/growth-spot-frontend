# Frontend — формы и валидация

## Основная форма
Ключевой пользовательской формой на сайте является форма заявки.

Она реализована в компоненте:

`src/components/sections/LeadForm.jsx`

## Поля формы
Форма содержит следующие поля:
- имя;
- телефон;
- сообщение.

## Используемая библиотека
Для работы с формой используется библиотека `react-hook-form`.

Она отвечает за:
- управление состоянием полей;
- валидацию;
- обработку отправки;
- отображение ошибок.

## Валидация
Логика валидации описана в файле:

`src/utils/leadValidation.js`

Frontend выполняет предварительную проверку данных до отправки запроса на backend.

### Имя
Поле имени проверяется по следующим правилам:
- допускаются только русские буквы;
- длина должна быть от 2 до 40 символов;
- цифры запрещены;
- разрешены пробел и дефис.

### Телефон
Поле телефона:
- нормализуется к российскому формату;
- приводится к виду `+7XXXXXXXXXX`;
- дополнительно форматируется для удобного ввода в интерфейсе.

### Сообщение
Поле сообщения:
- является необязательным;
- если заполнено, должно содержать минимум 5 символов;
- ограничено 1000 символами;
- проходит фильтрацию profanity;
- проходит фильтрацию мусорных символов и подозрительных данных;
- проверяется на наличие ссылок.

## Поведение при ошибке
Если backend возвращает признаки `blocked` или `spam`, frontend показывает сообщение о временной блокировке отправки по IP.

Это позволяет пользователю понять, что причина отказа связана не с поломкой формы, а с антиспам-ограничением.
