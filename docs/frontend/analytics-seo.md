# Frontend — SEO и аналитика

## Назначение
Frontend содержит отдельные компоненты для управления SEO-метаданными и подключения аналитики в публичной части сайта.

Эти механизмы используются только там, где они действительно нужны, и не подключаются в административном интерфейсе.

## SEO
Для управления SEO используется компонент `SEOHead`.

Он обновляет:
- `document.title`;
- `description`;
- Open Graph теги;
- Twitter теги;
- canonical URL.

Это позволяет задавать мета-информацию для отдельных страниц без ручного редактирования HTML-шаблона.

## Яндекс.Метрика
Для аналитики используется компонент `YandexMetrika`.

Он:
- загружает скрипт Яндекс.Метрики;
- берёт ID счётчика из настроек сайта;
- использует fallback ID, если значение не загружено;
- отправляет SPA page hit при смене маршрута.

Это позволяет корректно отслеживать просмотры страниц в одностраничном приложении.

## Источник конфигурации
ID Яндекс.Метрики подгружается через настройки сайта, полученные из backend.

Таким образом, изменение идентификатора аналитики возможно без изменения frontend-кода.

## Особенность
Яндекс.Метрика не подключается на страницах `/admin/*`.

Это сделано для того, чтобы:
- не смешивать поведение администраторов с публичной аналитикой;
- не отправлять служебные переходы внутри админки в метрику.
