# Frontend — деплой

## Общая схема
Frontend собирается из исходной директории проекта и публикуется как набор статических файлов.

Исходный код frontend находится в директории:

`/home/developer/project1/frontend`

Production-версия frontend размещается в директории:

`/var/www/project1/frontend`

## Сборка
Во время деплоя frontend собирается из исходников.

Если в проекте присутствует `package-lock.json`, используется:

`npm ci`

Если lock-файла нет, используется:

`npm install`

После установки зависимостей выполняется сборка:

`npm run build`

## Публикация
После сборки содержимое директории `dist/` синхронизируется в production через `rsync`:

`rsync -av --delete "$FRONTEND_SRC/dist"/ "$FRONTEND_PROD"/`

Такой подход:
- удаляет старые файлы, которых больше нет в сборке;
- обновляет production-версию сайта без ручного копирования;
- обеспечивает синхронность содержимого `dist/` и production-директории.

## Проверка
После деплоя frontend проверяется командой:

`curl -I https://growth-spot.ru`

## Связь с backend
Frontend ожидает backend API по пути `/api`, который проксируется nginx.

То есть:
- frontend обслуживается как статика;
- backend работает отдельно;
- API-запросы перенаправляются через reverse proxy.
