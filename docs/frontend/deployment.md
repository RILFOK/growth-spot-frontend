# Frontend — сборка и развёртывание (портфельная версия)

Этот репозиторий сохраняет предыдущую самостоятельную React/Vite-реализацию Growth Spot. **Рабочий сайт `growth-spot.ru` использует другой репозиторий — `RILFOK/growth-spot-nev` (Next.js).** Не копируйте файлы этого архива в действующий веб-корень и не перезапускайте из него PM2.

## Локальная проверка

```bash
npm ci
npm test
npm audit
npm run build
npm run preview -- --host 127.0.0.1
```

По умолчанию API ожидается по относительному пути `/api`. Для тестового backend задайте `VITE_API_URL` до сборки. Не помещайте в переменные Vite секреты: значения `VITE_*` доступны в клиентском JS.

## Структура сборки

Vite формирует `dist/index.html`, `dist/assets/*.js`, `dist/assets/*.css` и копирует ресурсы из `public/`. Плагин `vite-plugin-singlefile` больше не используется.

Для самостоятельного **стейджингового** хостинга публикуют всё содержимое `dist/`, а не только `index.html`. Для маршрутизации React SPA сервер должен возвращать `index.html` на неизвестных публичных путях, но проксировать `/api` отдельно в тестовый Express API.

## Перед любым внешним развёртыванием

Нужны тестовая база PostgreSQL, совместимая схема backend, проверка входа/2FA/ролей, корректная настройка proxy/trust proxy, разрешённые домены для аналитики, настоящая правовая информация и серверная защита авторизации. Файлы подтверждения права владения прежним доменом удалены из текущей портфельной сборки.

Историческая инструкция, автоматически перезапускавшая backend и синхронизировавшая production-каталоги с `--delete`, более не применяется.
