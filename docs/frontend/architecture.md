# Frontend — архитектура

## Общая схема
Frontend реализован как SPA-приложение на React и организован по файлово-модульному принципу.

Основная логика разделена между:
- страницами;
- компонентами;
- контекстами;
- API-клиентом;
- утилитами и пользовательскими хуками.

## Основные части

### `src/api`
Содержит Axios-клиент и общую логику авторизации через interceptors.

### `src/context`
Содержит глобальные контексты приложения:
- `AuthContext`
- `SettingsContext`
- `ThemeContext`

Эти контексты отвечают за состояние авторизации, настройки сайта и тему интерфейса.

### `src/components`
Содержит UI и бизнес-компоненты:
- публичные секции сайта;
- административные модули;
- layout-компоненты;
- SEO;
- аналитику;
- базовые UI-элементы.

### `src/pages`
Содержит страницы приложения:
- главную страницу;
- юридические страницы;
- административные страницы.

### `src/hooks`
Содержит пользовательские React-хуки.

### `src/utils` и `src/lib`
Содержат вспомогательные функции и утилиты, используемые в разных частях приложения.

## Корневой компонент
Приложение инициализируется в `src/main.jsx` и строится вокруг `src/App.jsx`.

В `App.jsx` подключаются:
- `ThemeProvider`
- `SettingsProvider`
- `BrowserRouter`
- `AuthProvider`

Такой порядок позволяет обеспечить глобальный доступ к настройкам темы, сайту, маршрутизации и состоянию авторизации.
